# Public profile checklist

Coded’s checklist turns already retrieved public GitHub metadata into a small set
of practical observations. It makes no additional request, does not edit GitHub
and stores no progress. The rules are deterministic and produce no score,
percentage, rank, proficiency or employability claim.

The account check reports whether GitHub returned a non-empty public biography.
Repository checks consider only original, non-archived repositories in the
retrieved sample. They report whether those projects have descriptions, detected
licences, and at least one discovery aid: a topic or project/homepage link. The
checklist also reports whether original public work is visible.

Completed checks appear as public strengths. Missing public metadata appears as
a suggested action, with links to at most three affected repositories. These are
presentation suggestions for an account owner, not criticisms of the developer
or the work.

If repository retrieval fails, Coded shows only the account-level check. A capped
or interrupted result is labelled, and unseen repositories are not assessed. A
complete result with no eligible project may suggest publishing an original
public project; an incomplete empty result does not make that claim.

The checklist cannot establish authorship, effort, code quality, private work or
whether a repository should have a demo, topic, description or licence. Account
owners retain control of all changes on GitHub.
